RAG Knowledge Assistant for TJH: 65% Faster Document Lookup Across All Properties

Case study summary

Executive summary

We built a RAG assistant over Thomas James Homes' leases, SOPs and local regulations that returns cited answers to leasing agents and property managers in seconds. Role-based access scopes each user to their properties. Document lookup time dropped 65% and new manager onboarding accelerated significantly.

The challenge

Leasing agents and property managers at TJH spent significant time hunting through leases, addenda, vendor contracts and local compliance rules spread across SharePoint, email threads and physical files. Answers were inconsistent from property to property and person to person.

New managers took weeks to get up to speed. Compliance questions often went unanswered until someone found the right document — and sometimes the answer never came at all.

What we built

A RAG assistant that ingests leases, SOPs, vendor contracts and local regulations and makes them searchable through a chat interface. Every answer includes the exact source citation — which document, which clause — so agents can verify and share it confidently.

Role-based access scopes each user to their properties. Syncs with Yardi automatically when lease data changes. The team asks in plain English and gets the answer with the evidence behind it.

The result

  • 65% faster document lookup across all properties.
  • New managers productive faster with cited answers from day one.
  • Consistent answers across properties — fewer compliance misses.
  • Agents spend time on leasing, not document hunts.
